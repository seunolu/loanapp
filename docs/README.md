# Nigerian Digital Lending Platform (Soft Loans)

This repo contains a regulated, audit-ready Nigerian digital lending system:

- Borrower mobile app
- Admin operations dashboard
- NestJS API (modular monolith)
- Ledger-first accounting + audit logs
